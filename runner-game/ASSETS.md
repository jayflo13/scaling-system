# Asset licenses

The game ships with **procedural colored-rectangle placeholders** (generated in
code), so it has **no third-party binary assets** by default and nothing to
attribute yet.

When you add real art/audio into `themes/<name>/assets/`, record each source
here. Stores will pull an app for IP/licensing violations, and CC-BY assets
require attribution even though they're free.

## Recommended free / commercial-use sources

| Type | Source | License notes |
|------|--------|---------------|
| Sprites / UI | [Kenney.nl](https://kenney.nl) | CC0 — no attribution required |
| Sprites | [OpenGameArt](https://opengameart.org) | Mixed — check each (CC0 / CC-BY / GPL) |
| Sprites | itch.io free packs | Per-pack license — read it |
| SFX | [Freesound](https://freesound.org) | Filter to CC0; others need attribution |
| SFX / music | Kenney audio packs | CC0 |
| Music | [Incompetech](https://incompetech.com) | CC-BY — attribution required |
| Fonts | [Google Fonts](https://fonts.google.com) | OFL |
