# 05 — Prompt Library (Copy-Paste)

Paste these into Claude or ChatGPT (free). Replace `[BRACKETS]`. Generate 3 variations, pick best.

---

## 1. Short-form script (the workhorse)

```
You are a short-form video scriptwriter who has written viral hooks for the [NICHE] space.
Write a 35-second vertical video script for [BRAND/CLIENT], whose audience is [TARGET AUDIENCE].
Topic: [TOPIC].

Requirements:
- A 3-second hook that creates curiosity or a pattern interrupt (give me 3 hook options).
- 3 punchy value beats, one idea each, spoken-word and casual.
- A soft CTA at the end (follow / save / DM).
- Mark on-screen TEXT overlays in [brackets] and suggested B-roll in (parentheses).
- Total spoken length ~90 words. No fluff, no intros like "in this video."
```

## 2. Hook generator (when you just need angles)

```
Give me 20 scroll-stopping 3-second hooks for [NICHE] short-form videos about [TOPIC].
Mix these styles: curiosity gap, bold claim, mistake/warning, "nobody tells you", number list,
before/after, myth-bust, question. Keep each under 12 words. Make me stop scrolling.
```

## 3. 10-video content batch (for a client month)

```
Create a 10-video short-form content plan for [CLIENT], a [NICHE] business whose goal is [GOAL].
For each video give: the content pillar, the hook (3-sec), a one-line concept, and the CTA.
Vary the pillars across: educational tip, myth-bust, list, story, before/after, hot take,
FAQ, behind-the-result. Make it a coherent month that builds authority and drives [GOAL].
```

## 4. Caption + hashtags (per video)

```
Write an Instagram/TikTok caption for a short video about [TOPIC] for [NICHE].
- 1 scroll-stopping first line, 2–3 lines of value, 1 CTA.
- Then 5 relevant, non-spammy hashtags (mix of mid and niche size).
Keep it human, not corporate.
```

## 5. Cold outreach personalizer (speed up DMs)

```
Here's a prospect's recent post/bio: "[PASTE THEIR CONTENT/BIO]".
Write a 1-sentence, specific, genuine compliment I can open a cold DM with. No flattery clichés,
reference the actual content. Under 20 words.
```

## 6. Sales objection responder (live, during a chat)

```
A prospect for my faceless short-form content service just said: "[THEIR OBJECTION]".
My offer: 3 free sample videos, then a batch of 10 for $250, money-back guarantee.
Write a short, confident, non-pushy reply that moves toward sending the free samples.
```

## 7. Niche picker (if unsure who to target)

```
I run a faceless short-form video service. I want the niche that (a) has money, (b) values content,
(c) is easy to reach by DM/email, (d) posts inconsistently so they need help.
Give me 7 candidate niches ranked by how fast I could close my first $250 client, with where to
find them and the specific pain I'd lead with for each.
```

---

### Usage tip
Always ask for **3 variations** and pick the best — the second or third is usually sharper than
the first. Your taste in choosing is the skill clients pay for.
