# 04 — The AI Delivery Pipeline (Free Tools)

How to turn a blank screen into a finished faceless short video in ~15–20 minutes. Once you've
templated it, you'll batch 10 in an evening. This is the "machine" part.

---

## The free tool stack

| Job | Free tool | Notes |
|-----|-----------|-------|
| Script + hooks + captions | **Claude / ChatGPT free** | Use `05-PROMPT-LIBRARY.md` |
| Stock B-roll | **Pexels, Pixabay** | Free, no attribution, commercial OK |
| AI-generated clips (optional) | **Higgsfield, Pika, Runware free tiers** | For original visuals |
| Voiceover | **ElevenLabs free tier** / TikTok native TTS | Or no VO — captions + music |
| Editing + captions + sound | **CapCut** (desktop or phone) | Auto-captions, trending audio |
| Thumbnails / text graphics | **Canva free** | Templates |
| Delivery | **Google Drive** | One folder per client |

You can do this entire pipeline **on your phone** with CapCut + Canva if needed.

---

## The 6-step production flow

### 1. Choose the angle (1 min)
Pick a content pillar for the client: *educational tip, myth-bust, before/after, list, story, hot take.*
Rotate pillars so their feed feels varied.

### 2. Write the script (3 min)
Paste the script prompt from `05-PROMPT-LIBRARY.md` into Claude/ChatGPT. Ask for a 30–40 second
script with a **strong 3-second hook**, 3 value beats, and a soft CTA. Generate 3, pick the best.

### 3. Get visuals (5 min)
- **Easiest (B-roll route):** Search Pexels/Pixabay for clips matching each line (e.g. "gym workout",
  "laptop coffee"). Download 4–6 clips.
- **Premium (AI route):** Generate 2–3 custom clips with an AI video tool for a signature look.
- Vertical 9:16 always.

### 4. Voiceover (3 min)
- Paste script into ElevenLabs free tier → download MP3. Or use CapCut/TikTok text-to-speech.
- **No-voice option:** skip VO entirely, use bold on-screen text + trending audio. Often performs best
  and is fastest.

### 5. Edit in CapCut (6 min)
- Drop B-roll on the timeline, trim each clip to ~2–3s (fast cuts = retention).
- Add the voiceover OR a trending sound (CapCut shows trending audio).
- **Auto-captions:** CapCut → Captions → Auto. Style them bold, centered, animated. Captions are
  non-negotiable — most people watch muted.
- Add a punchy text hook on screen for the first 3 seconds.
- Export 1080p.

### 6. Deliver (1 min)
Drop into the client's Google Drive folder, named clearly (`clientname_video01_hook.mp4`).
Include a one-line caption + 5 hashtags (generate with the caption prompt) and a suggested post time.

---

## Batching = the faceless machine

Don't make videos one at a time once you have a client. **Batch by step:**
1. Write all 10 scripts in one sitting (one prompt, ask for 10).
2. Pull all B-roll in one session.
3. Record/generate all 10 voiceovers back-to-back.
4. Edit all 10 using a **saved CapCut template** (same caption style, intro, outro) — just swap clips.

A templated batch of 10 takes **2–3 hours** once you're warmed up. That's the unit economics that
makes $1,000/mo retainers profitable on 3 hours/night.

---

## Quality bar (what separates $250 from $2,000)

- **Hook in 3 seconds** or nothing else matters. Test: would *you* keep scrolling?
- **Captions always**, styled and synced.
- **Fast cuts** — no clip longer than ~3s.
- **One idea per video.** Confused = scrolled.
- **Consistent look** per client (their colors/font) so the feed feels branded.

Save every winning format as a CapCut template. Your template library *is* your moat.
