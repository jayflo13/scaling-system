# Delivery Checklist (run per batch)

Quality control = renewals. Renewals = $10k/mo. Don't skip.

## Per video
- [ ] Hook lands in the first 3 seconds (would you stop scrolling?)
- [ ] Captions present, styled, synced, readable on mute
- [ ] Cuts every ~2–3 seconds, no dead air
- [ ] One clear idea + one CTA
- [ ] 9:16 vertical, 1080p export
- [ ] On-brand colors/font per intake
- [ ] Filename: `clientname_vidNN_topic.mp4`
- [ ] Caption + 5 hashtags written
- [ ] Suggested post time noted

## Per batch
- [ ] Pillars varied across the batch (not 10 of the same type)
- [ ] All files in the client's Google Drive folder
- [ ] Short delivery note sent: "Here's batch [N] — captions + post times in the doc. Approve or
      tell me what to tweak 👍"
- [ ] Logged each video in `content-calendar.csv`
- [ ] Calendar reminder set to check performance in 7 days (drives renewal pitch)

## After approval
- [ ] Asked for any tweaks within 24h (fast revisions = trust)
- [ ] If end of month: pitch the retainer
- [ ] If thrilled: ask for testimonial + 1 referral
